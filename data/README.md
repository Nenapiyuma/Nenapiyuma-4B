# Training data

Create data/train.jsonl using one JSON object per line:
{"messages":[{"role":"user","content":"..."},{"role":"assistant","content":"..."}]}

Suggested mixture: Sinhala 50%+, mixed Sinhala-English 15%, English 15%, coding 10%, maths/reasoning 10%.

Use only legally usable data and keep a source/license manifest. The repository does not ship fake training data or fake benchmark results.
